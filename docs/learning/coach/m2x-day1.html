Concepts (60-second read)

1 · Provider adapter One interface (complete()/transcribe()) in front of Groq/NIM/Ollama; model = HF repo id; routing is data in config/models.toml.Pitfall: if provider == "groq" branches leaking into feature code.
2 · Content-addressed cache Key = sha256 of everything that changes the answer: kind + model + provider + payload + params.Pitfall: hashing too little → silently stale answers.
3 · Retry + backoff 429/5xx retried, delay doubles, Retry-After wins; other 4xx never retried.Pitfall: retrying malformed requests burns quota to fail again.
4 · Run log One JSONL record per call, cache hits included; log write failure raises, cache write failure is swallowed.Pitfall: a measurement tool that silently loses records.
5 · Secrets boundary Keys only via Pydantic Settings as SecretStr; fetched per request; never logged.Pitfall: a stray repr/print leaking a key.
6 · Hermetic tests 129 tests, zero network (httpx.MockTransport), zero real clocks (injected sleep/monotonic); cost math tested with fake non-zero prices.Pitfall: free-tier $0.00 makes cost assertions vacuous.
