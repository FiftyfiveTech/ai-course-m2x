Block A · Corpus as an instrument (M2X-000)

A1 · A data boundary is written, not implied Internal FiftyFive meetings only, no client calls, consent given — and every exclusion listed with its reason, so the boundary is auditable.Pitfall: treating "I didn't include it" as documentation — nobody can tell excluded-on-purpose from forgotten.
A2 · Consent names a mechanism Teams recordings inside the FiftyFive tenant: participants see the recording notice before capture, chat names it afterwards, Saurabh attended both. Checkable by a third party.Pitfall: "consent given" as a bare assertion.
A3 · Register is a corpus axis Both internal meetings are Hinglish; Whisper returns Devanagari and transliterates "GPT" as "जीपीटी". With one register you can't separate "model is weak" from "audio is code-switched" — so 3 English AMI meetings (CC BY 4.0, whole meetings) were added as a control. 24 min → ~118 min.Pitfall: mistaking the control set for domain data. AMI has none of our vocabulary or screen-shares.
A4 · Verify instrumentally 16 kHz mono PCM confirmed by probe; usability measured as mean volume (−18.4 dB / −19.3 dB with near-full-scale peaks); screen-share confirmed by extracting frames at 25/55/85%.Pitfall: "I listened, it's fine" — not reproducible, doesn't survive the fresh-clone gate.
A5 · Dependency hygiene at the data edge fetch_ami.py reads encoded bytes instead of letting datasets 4.x decode through torchcodec; datasets+soundfile sit in an optional corpus group.Pitfall: a one-off fetch taxing every future uv sync.

Block B · The adapter and its invariants (M2X-010/011)

B1 · Provider adapter One interface (complete()/transcribe()) over Groq/NIM/Ollama; model named by HF repo id; routing is data in config/models.toml. All three speak OpenAI-compatible wire format, so one HTTP path varies only base URL + credential.Pitfall: if provider == "groq" leaking into feature code — then every switch is a refactor.
B2 · Content-addressed cache Key = sha256 of everything that changes the answer: kind + model + provider + payload + sampling params; audio hashed to a digest.Pitfall: hashing too little. Drop provider and a 3-provider comparison returns one provider's answer three times.
B3 · Retry + backoff 429/5xx retried with doubling delay; the provider's Retry-After beats the local guess; other 4xx never retried; the exhausted error names an escape hatch. Retries never multiply log records.Pitfall: retrying a malformed request — burns quota to fail identically.
B4 · Run log + asymmetric failure policy One JSONL record per logical call, cache hits included. Cache write failure is swallowed (an accelerator may degrade); log write failure raises (a measurement tool must never lose a record). Prices live in tracked config so cost is replayable.Pitfall: git-ignored prices → the cost report can't be reproduced on a fresh clone.
B5 · Secrets boundary Keys enter through one Pydantic Settings object as SecretStr, fetched per request, never stored on instances, never logged. Split rule: needed to reproduce a number → tracked config; leaking it compromises an account → .env.Pitfall: a stray print/repr in a traceback.
B6 · Hermetic tests 129 tests, zero network (httpx.MockTransport asserts the exact outgoing request per provider), zero real clocks (injected sleep/monotonic). The shipped routing config is validated by the suite.Pitfall: testing cost math at free-tier $0.00 — every assertion passes vacuously.

Block C · The Phase-0 slice (M2X-012)

C1 · Vertical slice first One command all the way through on real audio beats three polished layers that have never met — integration bugs surface on day one, not at the gate.
C2 · Three jobs, three seams CLI parses and prints; pipeline decides what happens to a meeting; adapter is the only thing that talks to a provider. The pipeline is handed an adapter and never builds one.Pitfall: logic in main() — untestable, so it stops being tested.
C3 · Timestamps are the foundation Segment-level output gives every text piece a t_start/t_end. Decision evidence, RAG citations, contradiction detection and frame OCR are all pointers into that axis.Pitfall: dropping timestamps at ingest — no citation layer can be added later at any price.
C4 · Return where the artefact went ProcessOutcome carries meeting id, transcript, transcript_path and optional summary, so the caller never re-derives the path.Pitfall: two copies of path logic that eventually disagree.
C5 · Untrusted data from the first prompt The summary system prompt already says the transcript is data and instructions inside it get summarised, never followed — before M2X-035 attacks it.Pitfall: retrofitting the injection rule after several prompts exist without it.

D2 · 262× and why Same model, same input, $0.00 both ways, cache hit at 0 ms on re-run. i5-1135G7 + Iris Xe that llama.cpp doesn't offload to → ~0.45 output tokens/s on CPU. Memory was never the limit (4.9 GB model, ~12 GiB free), so the bottleneck is compute.Pitfall: reading this as "local is bad". It's a fallback that keeps the pipeline runnable with no key and no network — build it to measure it.
D3 · A flag must not claim authority it lacks --provider ollama for the whole pipeline can't pass: whisper routes to Groq only and a forced provider that can't serve a model must raise. So --provider steers the summary (the hosted-vs-local switch) and --transcribe-provider steers transcription.Pitfall: "fixing" it with a silent fallback — then no number in the week can name the provider that produced it.
D4 · Portability floor ≠ token budget SUMMARY_INPUT_CHAR_LIMIT = 6000 exists because a quantised 8B on Ollama has a smaller default context than the same weights on Groq. Clamp inputs to the weaker environment or you measure the limits instead of the systems.
D5 · One file per meeting and provider Otherwise the second run silently overwrites the first and comparison work dies looking like success.

Cross-cutting: what these four tickets keep repeating

1 · Every decision that a number depends on is written down — design records, deviation notes, retros. Claimed ≠ verified; a gate number counts only when it reproduces on a fresh clone.
2 · Deviate from the spec when the spec defeats itself — in writing Three times so far: cache key (needs provider + params or the acceptance criterion is unsatisfiable), prices in tracked config (not .env), 5-min clip (10 min would duplicate the whole meeting), --provider scope.
3 · Never fall back silently Missing route, forced provider that can't serve, failed log write — all raise. Silence is what makes a measurement unattributable.
4 · Reproducibility is a design constraint, not a chore HF repo ids, tracked prices, uv.lock, mkdir -p under git-ignored data/, hermetic tests, optional dependency groups.
